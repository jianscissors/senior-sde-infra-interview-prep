# Interview Questions

Practice questions, organized by type. Recommended order:

1. [Classic system design questions](01-classic-system-design-questions.md) — general-purpose questions everyone gets (URL shortener, rate limiter, news feed, etc.), each linking through to a full detailed write-up.
2. [Infra-specific design questions](02-infra-specific-design-questions.md) — the questions that differentiate an infra-track loop from a generic backend one (distributed cache, job scheduler, service mesh, etc.). Spend the most time here.
3. [Deep-dive technical questions](04-deep-dive-technical-questions.md) — rapid-fire "explain how X works" questions, often asked as follow-ups mid-design.
4. [Behavioral & leadership questions](03-behavioral-and-leadership-questions.md) — senior-level bar-raiser questions, cross-linked to your [STAR story bank](../notes/star-stories.md).
